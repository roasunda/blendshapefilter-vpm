下のボタンを押すと、お使いの VCC（VRChat Creator Companion）または ALCOM が起動し、リポジトリ追加の確認画面が表示されます。

VCC / ALCOM に追加する
VCC または ALCOM がインストールされている必要があります。反応がない場合は、以下のURLを VCC / ALCOM の「Settings > Packages > Add Repository」に直接貼り付けてください。
https://raw.githubusercontent.com/roasunda/blendshapefilter-vpm/main/index.json
